# Refreshers

Quick rebrush material for picking back up after a study gap. Three files, each with a different rhythm — don't merge them back together.

| File | What it is | Rhythm |
|---|---|---|
| [`checklist.md`](./checklist.md) | Hands-on drill list — redo blind after a gap | Evergreen, edited in place |
| [`log.md`](./log.md) | Dated journal of study sessions | Chronological, append-only |
| [`backlog.md`](./backlog.md) | Practice todos + concepts parked for later | Todo list, prune as resolved |

Deeper concept write-ups belong in [`../Documentation/`](../Documentation/README.MD), not here — this folder links out rather than re-explaining.
